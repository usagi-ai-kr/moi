# ADR-0019: 0.2.0 문제은행·품질·관리 API

## 배경
- 0.2.0은 AWS SAA-C03 문제은행을 D1에 두고 AI가 제작·검수한 500문제를 관리 API로 등록한다. 문제 오류·편향·중복을 출시 전에 걸러야 한다.

## 결정
- **시험**: AWS Solutions Architect – Associate(SAA-C03). 한국어 문제·한국어의 간결한 해설, AWS 서비스명·공식 용어는 영문 유지. 실제 시험 문제/덤프 무단 복제 금지.
- **문제 수·배분**: 최초 공개 정확히 500문제. 영역 목표는 보안 150·복원력 130·성능 120·비용 최적화 100.
- **채점**: 단일·복수 선택, 선택지 고유 ID 집합 기준 완전 정답.
- **문제 필드**: 시험·영역·본문·보기·정답 수/ID·짧은 핵심 해설(권장 1~2문장)·AWS 공식 문서 근거 URL·검수/게시 상태·개정 이력.
- **식별자 분리**: 문제 ID·문제 개정 버전·보기 ID·화면상 번호/위치를 분리한다. 화면 번호·문제 순서·보기 위치에 정답 패턴이 생기지 않게 섞고 세트 내 중복을 금지한다.
- **자동 검수**: 정답 근거 일치, 모호성, 중복, 선택지 길이·정보량 편향, 정답 위치 편향, 해설 길이·형식을 검사한다. URL 유효성만으로 정답 타당성을 보장한다고 간주하지 않는다.
- **저장·관리 API**: 문제 원본은 D1. Hono/Workers 관리 API는 관리 토큰 인증의 JSON 일괄 등록+단건 CRUD, 수정/비활성화, 버전·감사 로그, 검수 실패 보고, 멱등 등록을 지원한다. 사용자 풀이 이력이 있는 문제는 물리 삭제 대신 비활성화한다.
- **시험 독립 구조**: 다른 자격시험의 데이터·영역·출제 정책을 저장할 수 있게 한다.
- **제작·게시**: 최초 500문제 생성·검수는 Mac mini AI 에이전트에서 실행하고 인증된 관리 API로 D1에 등록한다. 자동 검수 통과 즉시 게시 가능 상태가 되며 별도 수동 승인은 요구하지 않는다. 단 0.2.0 배포는 500문제 전량 통과 후다.
- **관리 토큰**: 카카오/PASETO 사용자 세션과 분리된 작업 주체별 토큰만 허용한다. 해시 검증·개별 폐기/교체·감사 로그·redaction, 브라우저 노출 금지를 적용한다.

## 결과
- 긍정: 시험별 확장 가능한 문제은행, 근거·편향·중복의 자동 차단, 감사 가능한 관리.
- 부정/제약: AI 검수 비용·오탐/미탐, 500문제 품질 게이트 운영 부담.

## 대안과 금지 사항
- 실제 시험 문제/덤프 복제, URL 유효성만으로 정답 승인, 관리 토큰의 브라우저 노출 — 금지.
- 풀이 이력이 있는 문제의 물리 삭제 — 금지(비활성화).
