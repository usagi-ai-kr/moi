# ADR-0032: 첫 화면 사실 문구·초기 렌더

## 배경
- home.note가 거짓(0.1.0 스캐폴드·로그인 다음 업데이트) — 실제는 로그인→20문제 풀이→저장/결과 동작 중.
- tagline이 AWS SAA만 제품 정체성으로 고정 — 0.2 목요일 수업 실사용은 문제 중심 플랫폼, AWS SAA는 첫 범위.
- 공개 제목/소개가 /api/me 완료까지 숨음 — LCP가 p.moi-note에서 1355ms 지연. 아이콘 단위 모바일 89/100/96/100, 게이트 90 유지 필요.

## 결정
- tagline=문제 중심 시험 대비 플랫폼, note=카카오 로그인→20문제 풀이→저장·결과 확인+현재 첫 범위는 AWS SAA.
- 미확정(loading/error)에도 h1/lead/note 즉시 렌더, 계정/학습/로그인 CTA는 서버 상태에만 따른다.
- 기존 로그인/로딩/취소/오류/로그아웃 흐름 유지, 가짜 비로그인/잘못된 CTA/개인정보 노출 금지.

## 결과
- 긍정: LCP 지연 제거(정적 콘텐츠 즉시 표시), 문구 사실성, 게이트 90 유지 기반.
- 부정/제약: error 시 로그인 CTA 없음(재시도로 복구), App 분기만 변경·CSS/토큰/인증로직 불변.

## 대안과 금지 사항
- 문구/스타일 숨김 점수 조작 금지, AntD 초기번들 편입 금지(ADR-0018), 폰트 preload 금지(ADR-0022).
