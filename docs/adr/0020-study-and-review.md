# ADR-0020: 0.2.0 20문제 풀이·오답/북마크 복습

## 배경
- 0.2.0의 핵심 학습 단위는 계정·시험별 20문제 세트와 오답/북마크 복습이다. 세트 스냅샷·일괄 채점·이력 보존이 필요하다.

## 결정 — 20문제 세트
- 계정·시험별 활성 20문제 세트는 **최대 하나**. 전체 범위, 특정 시험 영역, 취약 영역 추천을 통한 영역별 풀기를 지원한다. 다른 시험은 별개다.
- 전체 범위는 공식 영역 비중을 고려한 **가중 무작위**이며 세트마다 영역별 개수를 고정하지 않는다. 영역별 풀이는 선택 영역 안에서만 추출한다.
- 아직 풀지 않은 문제를 우선 채우고, 소진하면 전체 문제에서 **유효 누적 오답 횟수 가중** 확률로 추출한다. 최근 맞힌 문제·항상 맞힌 문제도 선택 가능하며 세트 내 중복은 금지한다.
- 시작 시 **문제 개정 버전과 보기 순서를 스냅샷으로 고정**한다. 새로고침·기기 변경·이어풀기 후에도 유지하고, 다른 회차에서 다시 만나면 보기 순서를 새로 섞는다.
- **20문제 최종 제출 시 일괄 채점**한다. 제출 전 정답은 비공개이며 시간제한·타이머·자동 제출은 없다.
- 답안 선택 / 의도적 Pass / 미응답을 구분한다. 미응답이 있어도 경고·확인 후 제출할 수 있고, Pass·미응답은 오답 및 복습 대상이다. 제출 전 Pass 취소·답변 변경이 가능하다.
- 제출 후 전체 20문제의 선택 답·정답·짧은 해설·AWS 근거 링크·북마크와 정답/오답/Pass/미응답·정답률 요약을 제공한다.
- 포기는 명시적 확인 후 `abandoned`로 기록하며 채점·진도·통계에 반영하지 않는다. 포기 당시 북마크는 유지한다. 완료/포기 후 새 세트를 시작할 수 있고 과거 세트를 날짜·영역·정답률 목록(페이지네이션)과 상세로 재조회한다.

## 결정 — 오답·북마크 복습
- 오답/Pass/미응답 제출 이력은 **계정별 영구 보존**하며 '현재 복습 필요' 표시와 분리한다. 다시 정답이어도 이력은 유지한다. 북마크는 개인별 독립 상태로 풀이 중·결과·해설에서 추가·해제한다.
- 오답 복습은 **유효 누적 오답 횟수 가중 무작위**, 북마크 복습은 **균등 무작위**다. 두 모드 모두 한 문제씩 즉시 채점하고 문제 수·시간 제한 없이 사용자가 종료한다.
- 모드별 독립 회차를 저장해 이어풀기를 지원한다. 회차 시작 시 대상·순서를 고정하고 회차 내 중복을 금지한다. 대상을 소진하면 최신 목록을 다시 섞어 다음 회차를 시작하며, 회차 중 대상 증감은 **다음 회차부터** 반영한다.
- 제출·채점된 개별 시도는 즉시 이력으로 보존한다. 미채점 문제는 종료 시 오답 처리하지 않는다.
- 오탈자/의미 동일 수정은 기존 가중치를 유지한다. 정답·문제 조건·실질적 보기 변경은 새 문제 버전의 가중치를 초기화하고 미풀이로 취급하되 원본 이력·북마크는 보존한다.

## 결과
- 긍정: 시험형 일괄 채점과 복습형 즉시 채점 분리, 데이터 유실 없는 이력·회차.
- 부정/제약: 스냅샷·회차·개정 버전 관리 복잡도.

## 대안과 금지 사항
- 제출 전 정답 노출, 타이머·자동 제출, 세트 내 중복, 포기의 통계 반영 — 금지.
- 채점 완료 결과 덮어쓰기, 미채점 복습 문제의 오답 자동 처리 — 금지.
