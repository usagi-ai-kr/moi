# ADR-0033: 0.2 수업용 500문제 원복과 생성·검증

## 배경
- 2026-10-19 사용자가 목요일(2026-10-22) 시험 준비를 위해 **원래 500문제를 빠르게 준비**하라고 지시했다("그냥 원본대로 해 … 빨리 문제 500개 내놓으라고").
- ADR-0030은 500문제·150/130/120/100 배분을 0.3으로 이관했으나, 이 사용자 지시로 **0.2 수업 사용 범위에 500문제를 다시 포함**한다.
- 외부 연결 AI/provider·Cron·자동 생성 파이프라인은 여전히 요구하지 않는다. 문제는 이 워크스페이스에서 작성한다.

## 결정
- 0.2 문제은행 목표를 **정확히 500문항, 보안 150·복원력 130·성능 120·비용 최적화 100**으로 복원한다(ADR-0019 배분 유지).
- 문항은 워크스페이스의 원본 JSON 팩(`content/questions/saa-c03/`)으로 작성한다. 실제 기출/덤프 복제를 금지하고 AWS 공식 문서만 근거로 쓴다.
- 등록 전 다음을 통과해야 한다.
  - 구조 검증기: 필수 필드·보기/정답 키·공식 URL·중복 ID/stem·정본 도메인 코드.
  - 품질 게이트: 문제 단위 편향/중복/해설 형식/근거 URL + 배치 단위 정답 위치·영역 분포·중복.
  - 로컬 등록 리허설: 관리 API bulk 5청크, 멱등 재실행, D1 건수·도메인 분포·정답/근거 저장, 500문항 `listPool` 조회.
  - 작성자와 다른 모델의 표본 교차 검토(치명·보통 결함 0).
- **500문항 전량 사람 검수 전에는 "검수 완료"로 표시하지 않는다.** 표본 교차 검토는 전량 검수를 대체하지 않는다.
- 실제 D1 등록·배포·실계정 smoke는 #127의 범위 확인 후 수행하고, 토큰·개인정보를 기록하지 않는다.
- 디자인·favicon·수업 실사용 확인(#132·#70·#131)과 0.3 이관 항목(#51·#53·#54·#55·#121·#128·#129 등)은 ADR-0030의 결정을 유지한다.
- 이 ADR은 ADR-0030을 대체한다. ADR-0030 본문은 보존하고 상태만 `Superseded by ADR-0033`으로 바꾼다.

## 결과
- 긍정: 수업 직전 필요한 문항 규모를 명확히 하고, 생성 볼륨과 검증 게이트를 분리해 대량 콘텐츠의 품질 위험을 드러낸다.
- 부정/제약: 500문항 생성·검수·등록은 시간이 많이 들고, 자동 게이트를 통과해도 사실 오류·모호성이 남을 수 있다. 표본 검토만으로 전량 정확성을 보장하지 않는다.
- 운영: 500문항 조회는 D1 bound parameter 상한(100)을 넘으므로 청킹이 필요하다. 로컬 miniflare는 상한을 강제하지 않아 실제 D1 smoke가 별도로 필요하다.

## 대안과 금지 사항
- 500문제를 0.3으로 유지 — 사용자 지시와 충돌하므로 채택하지 않는다.
- 외부 AI/provider/Cron으로 대량 생성 — 0.2 범위에서 금지한다.
- 덤프/기출 복제, 근거 URL 없는 문항, 사람 검수 없는 "검수 완료" 표시 — 금지한다.
- 500문항 전체를 자동 게이트만으로 "정답 검증 완료"라고 주장 — 금지한다.
