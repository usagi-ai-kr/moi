# ADR-0081: 학습·복습 회차 문제 수 4/8 선택

## 배경
- 본 학습·오답 복습·북마크 복습 모두 시작 전에 회차 문제 수를 4/8로 선택하게 한다.
- 기본값은 4문제다. 대상 문항이 부족하면 가능한 만큼만 출제하고 실제 가능 수를 명확히 안내한다. 가짜·중복 문항은 생성하지 않는다.
- 기존 10/20문제 세트의 읽기·이어풀기·제출·이력 호환은 유지한다.
- 세트 크기는 item 수로 파생하므로 D1 스키마·마이그레이션·인증·Secrets를 변경하지 않는다.

## 결정
- 새 학습 세트 크기는 4 또는 8 중 선택하며 기본값은 4다. 풀/필터 결과가 요청보다 적으면 가능한 수만큼 세트를 만들고, 0이면 명확한 거부 사유를 반환한다.
- 복습 회차 크기 역시 4 또는 8 중 선택하며 기본값은 4다. remaining이 요청보다 적으면 가능한 수만큼 회차를 생성한다.
- 새 세트/회차는 1~8문항을 허용하고 0문항·중복·빈 보기 순서는 거부한다. 기존 10/20 세트는 읽기/제출 경로에서 크기를 강제하지 않는다.
- ADR-0046은 Superseded by ADR-0081으로 표시한다.

## 결과
- 긍정: 사용자가 회차 부담을 4/8로 선택할 수 있고, 부족 시 실제 가능 수를 안내받는다. 기존 세트 호환이 유지된다.
- 부정/제약: 10/20 세트와 4/8 세트가 이력에 혼재한다(정답률은 세트 내 비율이라 비교 가능).

## 대안과 금지 사항
- 가짜·중복 문항 생성 금지. 부족 시 가능한 만큼만 출제.
- #274 파일 디자인 변경 금지(최소 텍스트 안내만 StudyScreen/ReviewScreen).
- D1 스키마·마이그레이션·인증·Secrets 변경 금지.
