# ADR-0094: 푸터·빌드 메타데이터 표시 정책

## 배경
- 푸터 날짜는 글리프가 밑줄처럼 보일 수 있고 PR 번호를 보여줄 공간도 없다.
- 배포본의 빌드 버전·PR·시각은 개발자 도구에서 한 줄로 확인할 수 있어야 한다.

## 결정
- 푸터는 마일스톤에서 선택한 버전만 `v{semver}`로 표시한다. 기존 중앙 정렬과 muted 색상을 유지하며 날짜와 PR 번호는 푸터에 표시하지 않는다.
- Vite 빌드는 기존 fail-closed 마일스톤 조회로 버전을 결정하고, 빌드 시 `git log -1 --format=%s`에서 `(#NNN)` 형식의 마지막 PR 번호를 읽는다. 로그 조회·파싱에 실패하면 빌드를 계속하고 PR 표시는 `#unknown`으로 한다.
- 빌드 시각은 KST `yyyy-MM-dd HH:mm` 형식으로 고정한다.
- `bootstrap/web` 진입점은 앱 부팅 때 콘솔에 `moi v{version} · #{PR|unknown} · {yyyy-MM-dd HH:mm} KST` 한 줄을 한 번 출력한다. UI 계층은 이 로깅 함수를 가져오지 않는다.

## 결과
- 긍정: 사용자가 보는 푸터는 간결하게 유지되며, 빌드 출처와 시각은 개발자가 콘솔에서 확인할 수 있다. PR 번호 부재는 빌드를 막지 않는다.
- 부정/제약: PR 번호는 HEAD 커밋 제목의 `(#NNN)` 표기에 의존하며, 패턴이 없거나 git 로그를 읽지 못하면 `#unknown`이 표시된다. 빌드 시각은 분 단위다.

## 대안과 금지 사항
- 날짜·PR 번호를 푸터에 함께 표시하는 대안은 선택하지 않는다.
- 브라우저 UI 모듈에서 콘솔 출력을 실행하거나 비밀값·환경변수를 빌드 메타데이터에 포함하지 않는다.
