# ADR-0030: 0.2 학습 실사용·디자인과 0.3 이관

## 배경
- 0.2는 목요일(2026-10-22) 학습 실사용까지만 완료한다. 다른 확장은 0.3이다.
- 문제는 이 워크스페이스에서 작성한다. 연결 AI/provider·자동생성/Cron은 요구하지 않는다.
- favicon·OS 아이콘과 실제 화면 디자인은 사용자가 보고 싶으므로 0.2에 포함한다.
- Milestone 번호 유지: 9=0.2.2 저장·복구, 10=0.2.3 워크스페이스 작성·등록, 11=0.2.4 학습 실사용·디자인, 12=0.3.0 후속.

## 결정 — 0.2 학습 실사용 범위
- 0.2.0 기존 문제은행 기반 → 0.2.1 20문제 풀이/제출/결과/이력 → 0.2.2 세트 저장·복구·단일세션 → 0.2.3 워크스페이스 문제 작성·검증·등록(#134) → 0.2.4 학습 실사용·화면 디자인·favicon 확인(#132·#70, 사용자 확인 #131 qus0in).
- 문항 범위/수는 #131에서 사용자가 확인한다. 정확 500문제·영역 150/130/120/100과 일반공개 Phase1은 실사용 gate가 아니다.
- 원격 D1 등 실행 확인은 #127을 따르고, AI Secrets 요청은 하지 않는다.

## 결정 — 0.3 이관
- 0.3: 복습 확장(#51), 신고/자동재검수/정정(#53), 통계/취약추천/복습runtime(#54), AI/provider/Cron/추가운영(#55), 공개정책/라이선스(#121/#128/#129), SEO/라우팅확장/라이브러리비교(#65/#71/#72).
- 이미 병합된 코드 제거·보안 퇴행을 금지한다. PR #130/#133은 0.3 draft로 유지하고 원자저장 212a518·라이선스 81088dd 브랜치를 보존한다.
- 학습 사용에 일반공개 릴리스 준비를 요구하지 않는다. 정식 minor 완료 주장 시 wiki/tag/Release/release branch 4종 규칙을 유지한다.

## 유지되는 기존 계약 (삭제·축소 금지)
- 인증/소유권: Kakao OIDC+PKCE·PASETO 24h·user_id 소유권·(kakao,sub) UNIQUE·토큰 브라우저 저장 금지.
- 문제은행: 한국어 본문/해설·영문 용어·덤프 금지·필드/개정/멱등·비활성화·관리토큰 분리.
- 풀이: 스냅샷 고정·제출 전 정답 비노출·일괄채점·Pass/미응답 구분·abandoned 제외·이력 보존.
- 저장안전: D1 진실원천·서버성공 전 완료표시 금지·단일세션·충돌병합·채점덮어쓰기 금지.
- 신고/정정·통계 계약(신고임계·중지/확정구분·정정재계산) 유지는 0.3 규칙이다(0.2 gate 아님).

## 결과
- 긍정: 목표 날짜에 맞춘 최소 사용 범위 고정, 0.3 경계 명확화, 기존 계약 유실 방지.
- 부정/제약: 0.3 항목은 미지원 안내, 미구현을 완료처럼 소개하지 않는다.

## 대안과 금지 사항
- 0.2에 연결 AI·Cron·500문제 전량·일반공개 준비 추가 — 금지(0.3).
- 병합 코드 삭제·보안 퇴행·릴리스 4종 없는 정식완료 주장 — 금지.
