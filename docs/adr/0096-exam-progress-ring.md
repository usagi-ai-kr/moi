# ADR-0096: 시험 전체 진척도 지표와 표시 계약

## 배경
- #353은 현재 선택한 시험에서 학습을 완료한 고유 문항 비율을 홈과 시험 컨텍스트 화면에 지속적으로 보여 준다.
- 오답·북마크·미제출 답안 등을 완료로 계산하지 않도록 진척도의 기준은 서버 통계 계약(#330·#311)을 따른다.

## 결정
- `GET /api/study/stats` 응답의 선택 시험 `coverage`를 유일한 표시 원천으로 사용한다. 브라우저에서 이력이나 시도 목록을 다시 집계하지 않는다.
- 헤더 진척도와 학습 현황의 요약·영역 통계는 같은 시험 ID·사용자 ID query key를 사용해 캐시와 서버 요청을 공유한다. 이전 시험·사용자 값을 새 키의 placeholder로 표시하지 않는다. 학습·복습 답안 제출 성공 후 통계를 무효화한다.
- 시험 선택기 바로 뒤에 인라인 SVG 링과 숫자 퍼센트를 함께 표시한다. 화면 읽기에는 하나의 `progressbar` 이름과 현재값만 제공하고, SVG는 장식으로 숨긴다.
- 퍼센트는 소수점 첫째 자리까지 반올림한다. 정수인 값은 소수점을 생략한다.
- 최초 조회 중에는 로딩 상태를 표시하고, 분모가 없거나 0인 경우와 조회 실패·시험 불일치·잘못된 값은 0%로 꾸미지 않고 미조회 표시를 사용한다. 통계 요청은 학습·시험 선택 UI를 막지 않는다.
- 링은 기존 AWS 오렌지 및 경계 토큰을 사용한다. `/account`에는 시험 선택기와 진척도를 표시하지 않는다.

## 결과
- 긍정: 완료 비율의 정의가 서버 통계 및 이후 화면과 일치한다. 사용자·시험 간 값이 섞이지 않고 접근성 이름과 시각 표현이 함께 제공된다.
- 부정/제약: API가 통계를 제공하지 못하면 최근 값을 추측해 보여 주지 않고 미조회 상태를 표시한다. 소수점 첫째 자리 반올림으로 더 작은 변화는 화면에 바로 드러나지 않을 수 있다.

## 대안과 금지 사항
- 로컬 학습 이력으로 비율을 다시 계산하거나, API 오류를 0%로 처리하지 않는다.
- 별도 차트 라이브러리 대신 작은 인라인 SVG를 사용해 추가 의존성과 화면별 구현 차이를 만들지 않는다.
