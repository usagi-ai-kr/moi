# ADR-0044: 해설 Mermaid 노드 라벨 인용 규칙

## 배경
- `saa-res-0129` 해설의 `G[Global Accelerator (고정 IP)]`가 Mermaid 12.2.0에서 `Parse error`로 실패해 도식 대신 원문 폴백이 노출됐다.
- 학습은 유지되지만 도식이 사라지고, 같은 유형이 콘텐츠 작성마다 반복될 수 있다(#134, #168).
- 기존 품질 게이트(#48)에는 Mermaid 문법 검사가 없어 사람 리뷰로만 잡혔다.

## 결정
- 노드 라벨에 예약 문자(`( ) [ ] { } " | @`)가 있으면 큰따옴표로 인용한다(`G["Global Accelerator (고정 IP)"]`).
- 도메인 규칙 10 `mermaid-label`을 추가해 `mermaid` 코드 블록의 노드 라벨만 검사한다. 간선 라벨(`-->|...|`)은 구분자로 닫히므로 검사하지 않는다.
- 검사는 순수 함수다(ADR-0001): Mermaid을 실행하지 않고 펜스 추출·셰이프별 라벨 스캔(예: `[]`, `[[]]`, `(( ))`, `{{ }}`)·예약 문자·인용 여부만 판정한다.
- 위반은 문제당 첫 건만 보고한다(블록 → 줄 → 라벨 순, 결정적). `checkId: 'mermaid-label'`로 다른 규칙과 동일하게 집계한다.

## 결과
- 긍정: 콘텐츠 파싱 실패가 PR 품질 게이트에서 차단되고, 원인(라벨·예약 문자)이 사유에 그대로 드러난다.
- 부정/제약: 문법 판정은 Mermaid 파서의 완전한 대체가 아니다(중첩·멀티라인 라벨 등 미지원). 규칙 확장 시 실제 파서 실측 케이스를 근거로 추가한다.
- 기존 콘텐츠 재등록은 #127 승인 범위에서 별도로 다룬다(이 결정은 품질 게이트만 강화한다).

## 대안과 금지 사항
- Mermaid 파서를 CI에 직접 호출 — 도메인 순수성·번들 경계(ADR-0011) 위반과 무거운 의존으로 기각.
- 예약 문자 라벨 금지 — 학습에 필요한 괄호 표기를 막아 콘텐츠 표현력을 해친다. 인용으로 허용한다.
- 인용 누락을 리뷰어 판단에만 맡기는 것 — 재발 방지가 없어 기각.
