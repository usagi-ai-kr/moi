# ADR-0015: src 모듈 길이 예산 — 하네스·src 통합

## 배경
- ADR-0013은 하네스 모듈(AGENTS·SKILL·ADR)에만 예산을 뒀다. `src/` 제품 코드 비대화는 차단되지 않았다(이슈 #41).
- 큰 src 모듈은 리뷰·컨텍스트 비용을 키우고 단일 책임을 해친다. 위반을 분할 신호로 쓴다.

## 결정 — src 예산 (측정: 줄·바이트 · 추정토큰=bytes/3)
| 모듈 | 목표 | 상한(초과 시 실패) |
| --- | --- | --- |
| `src/**/*.{ts,tsx,css}` | 150줄 | 250줄 / 16KB |
| 하네스 3종(기존 유지) | ADR-0013과 동일 | 동일 |

- **검사 도구**: `check-module-lengths.mjs`에 `**` 재귀·`{a,b}` brace 확장을 추가. `**` 탐색은 숨김 디렉터리·`node_modules` 제외. 확장 0건은 기존처럼 WARN.
- **CI**: 동일 스크립트를 `.github/workflows/ci.yml`에서 항상 실행(fail-closed) — 초과 시 PR 차단.
- **해소**: ADR-0013 절차(중복 제거→스크립트화→분리) 동일. 예산 변경은 본 ADR 갱신(supersede) + `budgets.json` 동시 수정.

## 결과
- 긍정: src 비대화를 PR 단계에서 차단, 하네스·src 예산 단일 설정(`budgets.json`)으로 통합.
- 부정/제약: 상한 근접 시 분할 작업 필요(의도된 정리 트리거).

## 대안과 금지 사항
- src 전체 단일 파일 예외 — 채택하지 않음(경계·분할 관성 약화).
- 상한 초과 코드의 예산 무단 상향 — 금지(ADR 갱신 필요).
