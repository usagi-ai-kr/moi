# ADR-0014: 디자인 시스템 보강 — 폰트 제공·UI 제약 예외·여백·Lighthouse·카카오 버튼

## 배경
- #34 리뷰·사용자 지시(2026-10-18): 폰트 라이선스 검증, UI 제약 예외 명확화, Lighthouse 재현성, 카카오 버튼(공식 심볼·핵심 색), 요소·경계가 붙지 않게(기본 패딩 유지).
- 라이선스 검증(눈누 #674 원문): **웹사이트·서버 내 폰트 탑재(임베딩) 허용**, 단 **수정·편집·개작 금지(배포된 형태 그대로 사용)**, 유료 판매·비용 청구 금지 → 공개 저장소에 폰트 바이너리를 두는 재배포 리스크를 제거한다.

## 결정
- **폰트 제공**: KoddiUD는 공식 웹폰트 경로(눈누 제공 jsdelivr)를 `tokens.ts`의 `typography.displayFontUrl` 단일 값으로 쓰고, 첫 페인트·로드 이후(`load`+1.2s) `<style>`로 지연 주입한다. **저장소에 바이너리를 두지 않으며**, 서브셋·포맷 변환 등 수정을 금지한다. 역할: 표시(브랜드/제목)=KoddiUD 700, UI=Inter Variable(+한글은 시스템 폴백 — `fontUi` 스택에 KoddiUD 미포함), 로드 전·실패 시 Inter→시스템으로 렌더(`swap`).
- **UI 제약 예외(ADR-0012 개정)**: ① hover — **전용 의존 UX 금지**(호버는 보조 강화만) + 키보드 `focus-visible`·터치 동등 동작 보장 ② position — 기본은 fixed 수준, **모달·드롭다운·툴팁 등 배치에 필요한 예외 허용**(사유 기록) ③ 간격 — container 내부 padding **+ flex/grid gap 병행**.
- **여백 가드레일**: 모든 컨텐츠는 container 내부에서 렌더 — 요소 간 최소 8px, 화면단 최소 `clamp(16px, 5vw, 32px)`, **페이지 기본 패딩 축소 금지**.
- **카카오 로그인 버튼**: 카카오 공식 디자인 가이드 — 컨테이너 `#FEE500`·말풍선 **심볼 `#000000`**(형태·비율·색 변경 금지, CI/기능 아이콘 대체·심볼 생략 금지)·레이블 `#000000 85%`·시스템 서체·radius 12px. 심볼 패스는 공식 리소스 SVG에서 추출, 값은 `tokens.ts`의 `kakao`가 단일 소스. 진입점 `/auth/kakao`(연동은 0.1.1).
- **Lighthouse 재현성**: 대상=홈(`/`)·변경된 주요 화면 / 모드=CLI 모바일 기본(데스크탑 보조) / 실행=`run-lighthouse.mjs`(빌드+preview+측정, <90 시 exit 1) / 반복=기본 1회(기준 ±5 근접·변동 시 `--runs 3` 최저값) / 환경=로컬 프로덕션 빌드(Chrome·`CHROME_PATH` 허용), 배포 후(0.1.4) 실 URL 동일 절차 / 미달 시 원인·후속을 PR에 기록. Playwright(오버플로·가시성) 검증과 역할 분리.

## 결과
- 긍정: 라이선스 리스크 제거(저장소에 바이너리 없음)·재현 가능한 성능 게이트·브랜드 규정 준수·여백 일관성.
- 부정/제약: KoddiUD는 외부 CDN 의존(지연 로드·폴백), 첫 페인트에는 폴백 폰트로 표시.

## 대안과 금지 사항
- 폰트 바이너리 저장소 커밋·CDN 재배포·폰트 수정(서브셋·변환) — 금지. 카카오 심볼 생략·색 변경 — 금지.
