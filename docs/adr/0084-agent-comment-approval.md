# ADR-0084: 에이전트 코멘트와 사용자 승인 구분 — 우선순위·범위 변경 규칙

## 배경
- 에이전트가 사용자 계정으로 남긴 "후속 분리" 코멘트를 사용자 결정으로 오인해 #274/#275를 우선순위에서 제외한 사례가 있었다. 사용자 지시로 정정했다.

## 결정
- 에이전트가 사용자 계정으로 남긴 이슈/PR 코멘트는 사용자 승인으로 간주하지 않는다. `[agent]` prefix를 필수로 붙인다.
- 우선순위 변경·범위 제외·후속 이관은 사용자 명시 승인 링크 없이는 금지한다.
- 디스패치 전 이슈 라벨·Milestone과 사용자 최신 지시를 대조한다.
- `agent-orchestration`·`issue-triage` 스킬과 AGENTS.md에 동기화한다(#288).

## 결과
- 긍정: 우선순위 오판 방지, 승인 근거 추적성 향상.
- 부정/제약: 승인 링크 확인 절차가 늘어난다.

## 대안과 금지 사항
- 에이전트 코멘트를 승인으로 간주 금지.
- 사용자 지시 없는 `focus` 이슈 후속 이관 금지.
