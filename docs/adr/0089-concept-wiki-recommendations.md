# ADR-0089: 개념 위키 정적 문서와 개인화 추천 점수

## 배경
- 오답과 북마크를 합친 개인별 개념 읽기 추천이 필요하지만, D1의 문항 PK는 콘텐츠 파일의 안정 ID와 다르다.
- 새 설명을 생성하지 않고 검수된 정적 문서와 공식 근거를 제공해야 한다.

## 결정
- 시험별 정적 문서는 `content/concepts/<examCode>/catalog.json`에 두고, 저장소 문제 팩의 안정 `questionId`별 개념 태그를 별도 매핑한다. 추천·상세 API와 빌드 인덱스는 `reviewStatus: reviewed`와 유효한 `reviewedAt` 날짜가 모두 있는 문서만 사용한다.
- 빌드 전 생성하는 Worker 전용 인덱스는 콘텐츠 문제의 공백 정규화·소문자화 stem SHA-256을 저장한다. 런타임은 현재 활성 버전의 stem fingerprint로 정확히 매칭한다. 매칭 실패·태그 부재 문항은 추천에서 제외하고 근거 부족으로 간주한다.
- 추천 입력은 인증된 사용자의 현재 시험에서 유효 오답과 북마크의 합집합이다. 같은 문항은 한 번만 반영하며, 유효 오답 수는 문항별 3회분까지만 가중한다.
- 문항별 점수는 유효 오답 1회당 2점(최대 6), 최근 오답 가점(7일 이내 3점, 8–30일 2점, 31–90일 1점), 북마크 2점이다. 90일이 지난 오답에는 최근성 가점을 주지 않는다.
- 개념 점수는 해당 개념에 매핑된 고유 문항 점수의 합이다. 점수 내림차순, 고유 관련 문항 수 내림차순, 개념 ID 오름차순으로 정렬해 최대 16개만 반환한다. 설명의 선정 이유는 오답·최근 오답·북마크 문항 수로 재현한다.
- 목록 API에는 짧은 제목·선정 이유·관련 문제 수만 반환한다. 선택한 개념만 별도 API로 본문·비교·공식 출처·관련 문제를 가져온다.
- 출처 문제 ID는 서버 내부에서만 쓰고 사용자 응답·화면에 노출하지 않는다. 인증 사용자·현재 시험 외의 데이터는 조회하지 않는다.

## 결과
- 긍정: 개인별 결과가 동일한 입력·기준일에서 재현되고, 중복 오답의 과도한 영향이 제한된다. 콘텐츠 문서가 없는 개념은 근거가 있는 것처럼 표시하지 않는다.
- 부정/제약: stem 수정 시 지문 fingerprint 매핑을 다시 생성해야 한다. SAA-C03 정적 팩에 존재하지 않거나 정확 매칭되지 않는 문제는 추천 범위에서 빠진다. 시험 확장에는 시험별 콘텐츠 태그·공식 출처 검수가 필요하다.

## 대안과 금지 사항
- 생성형 AI 설명 생성은 정확성·비용·보안 검토와 별도 ADR 승인 전까지 사용하지 않는다.
- D1 스키마 변경으로 안정 콘텐츠 ID를 도입하는 대안은 이번 MVP에서 보류한다.
- 동적 키워드 추정으로 검수되지 않은 설명·문항 매핑을 노출하지 않는다.
