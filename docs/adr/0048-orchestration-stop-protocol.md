# ADR-0048: 작업 정지 절차와 브리프·보고서 절대 경로

## 배경
- 2026-10-20 사용자가 "인수인계를 위한 이슈와 프롬프트만 남기고 모두 중지"를 지시했다. o는 진행 중이던 Draft PR 생성을 이어가려다 자동 승인 검토에서 범위 밖 외부 변경으로 거부됐고, 인계 이슈·프롬프트를 남기기 전에 세션이 끝났다.
- 같은 날 r 보고서가 `$TMPDIR/opencode/` 바로 아래(`moi-work` 밖)에 생기고, `$TMPDIR` 값이 `/var/...`와 `/private/var/...`로 섞여 o가 경로를 혼동했다.
- ADR-0042(역할·콜백)는 유지한다. 이 ADR은 정지 시 절차와 경로 규칙을 보완한다.

## 결정
- **정지 지시를 받으면** o는 새 외부 쓰기(PR·이슈 생성·병합·배포·push·새 단위 디스패치)를 즉시 멈춘다. 허용 범위는 지시가 명시한 인계 산출물뿐이다.
- 정지 순서: ① 각 패널에 중지 프롬프트(실행 중 테스트·서버 종료, 미커밋 변경 보존, 3줄 상태 응답 후 대기, 콜백 불필요) ② 폴백 타이머 해제 ③ 브랜치·SHA·미커밋·잔여 프로세스 확인 ④ 인계 문서(`docs/handover/`)와 추적 이슈 갱신, 다음 o용 재개 프롬프트 포함.
- 미커밋 워커 변경은 폐기하지 않는다. 인계 시 해당 브랜치에 `wip:` 커밋으로 보존하고, 게이트 미검증임을 커밋 메시지와 인계 문서에 표시한다.
- 브리프·보고서·로그 경로는 **절대 경로**로 전달한다. 기준 디렉터리는 `$TMPDIR/opencode/moi-work/`이며, 보고서가 다른 위치에 생기면 o가 인계 문서에 실제 경로를 기록한다.

## 결과
- 긍정: 정지 지시 후 범위 밖 외부 변경 방지, 인계 누락 방지, 경로 혼동 제거.
- 부정/제약: 정지 시점의 WIP 브랜치가 늘어나며, 재개 시 각 WIP을 다시 검증해야 한다.

## 대안과 금지 사항
- 정지 지시 후 진행 중 단위의 PR·병합·배포를 "마무리"로 간주해 계속하는 것 — 금지.
- 미커밋 변경을 `git stash`·`checkout`으로 버리는 것 — 금지.
