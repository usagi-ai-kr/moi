# ADR-0013: 하네스 모듈 길이 예산 — 검사·관리 자동화

## 배경
- 하네스 모듈(AGENTS.md·SKILL.md·ADR)은 에이전트 컨텍스트로 반복 로드된다. 길이 예산이 없으면 컨텍스트 비용·리뷰 부담이 계속 커진다(사용자 지시 2026-10-18).
- Agent Skills 표준은 본문 500줄 이하를 권장하지만, moi는 스크립트 중심 운영(요약 출력만 읽기)이므로 더 엄격한 상한을 둔다.

## 결정 — 모듈별 예산 (측정: 줄·바이트 · 추정토큰=bytes/3)
| 모듈 | 소비 방식 | 목표 | 상한(초과 시 실패) |
| --- | --- | --- | --- |
| `AGENTS.md` | **항상** 로드 | 110줄 | 120줄 / 12KB |
| `.agents/skills/*/SKILL.md` | 트리거 시 로드 | 90줄 | 120줄 / 12KB |
| `docs/adr/*.md` (README 제외) | 선택 열람 | 40줄 | 60줄 / 4KB |
| 스크립트·생성물(ADR README) | 실행·자동 생성 | — | 검사 제외 |

- **검사 도구**: `node .agents/skills/harness-budget/scripts/check-module-lengths.mjs` — 상한 초과 시 exit 1(목표 초과는 경고). 예산 단일 설정은 `budgets.json`(`--json` 지원).
- **CI**: `.github/workflows/ci.yml`에서 항상 실행(fail-closed) — 초과 시 PR 차단.
- **초과 해소 절차**: ① 중복·군더더기 제거 ② 반복·결정적 절차의 스크립트화 ③ 상세 분리(링크만 유지). 예산 변경은 본 ADR 갱신(supersede) + `budgets.json` 동시 수정.

## 결과
- 긍정: 모듈 비대화를 PR 단계에서 차단, 컨텍스트 비용 상한 보장, "문서 대신 스크립트" 관성 강화.
- 부정/제약: 상한 근접 시 분리 작업 필요(의도된 정리 트리거). 자동 생성물(ADR README)은 검사 제외.

## 대안과 금지 사항
- 전역 단일 상한(모듈 소비 방식 무시) — 채택하지 않음(항상 로드 모듈이 과대 허용됨).
- 상한 초과 문서의 예산 무단 상향 — 금지(ADR 갱신 필요).
