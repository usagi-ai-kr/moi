# ADR-0021: 0.2.0 저장·복구·단일 세션·신고·정정·통계

## 배경
- 0.2.0은 학습 진도·답안·복습·통계를 계정별로 보존하고 문제 오류 신고·채점 정정을 감사 가능하게 처리한다.

## 결정 — 저장·복구·세션
- **D1이 진도/답안의 진실 원천**이다. 세트·회차·문제/보기 스냅샷·답안·채점·북마크를 user UUID/시험 ID로 저장한다.
- localStorage=계정별 미전송 답안 초안, sessionStorage=탭 UI. PASETO/세션/관리 토큰은 브라우저 저장소에 저장하지 않는다(ADR-0005/0006).
- 저장 상태(저장 중/서버 저장됨/오프라인/충돌)를 실제대로 표시하고 **서버 성공 전 완료 표시를 금지**한다. 재연결 후 재전송하며 중복 제출·세트 생성에 멱등성을 적용한다.
- **계정당 단일 활성 PASETO 세션**. 새 로그인 시 기존 jti를 폐기하고 이전 기기 API를 401·만료 안내한다. 이전 기기 초안은 계정별 보존하며 같은 계정 재로그인 후 복구한다(기기간 전송 금지).
- 복구 시 다른 문제는 병합하고 같은 문제는 사용자 선택을 받는다. 채점 결과 덮어쓰기를 금지하고 중복 제출·구세션 경쟁에 멱등·원자성·버전 검사를 적용한다.
- 로그아웃/계정 전환 시 다른 계정의 초안이 노출되지 않도록 격리·정리한다.

## 결정 — 신고·검수·정정
- 문제 버전별 **고유 신고 계정 / 푼 고유 계정**으로 신고율을 계산하고 동일 계정 반복 신고는 1명으로 집계한다.
- **고유 신고 ≥5 AND ≥10%** → 즉시 자동 출제 중지. 신고 ≥1 → 일일 Cron AI 재검수(재시도·중복 방지·감사).
- 실제 오류 확인 → 신고 수와 무관하게 중지. AI는 근거·수정안만 생성하고 운영 변경은 관리 API, 새 버전 검수 후 재공개한다.
- 진행 중 세트는 스냅샷을 유지하되 오류 문항을 채점 제외하고 유효 분모로 계산한다. **잠정 중지와 확정을 구분**한다.
- 완료 세트는 최초 답안/채점을 보존하고 정정 이벤트로 문항 제외·점수/오답 통계/추천을 재계산한다. 알림 없이 최초/정정/사유만 표시하고 분모 0은 **채점 불가**로 표시한다.

## 결정 — 학습 현황
- 최초 풀이 고유 문제/500, 누적·영역 정답률, 취약 추천(정답률+최소 표본+최근 성과)을 제공한다. 반복 영향은 제한하고 표본 부족 영역을 취약으로 단정하지 않는다.
- 시험 확장 시 로그인은 공유하되 진도·오답·북마크·취약·이력은 시험별로 분리한다.

## 결과
- 긍정: 데이터 유실 방지·기기 격리·감사·시험별 확장. 부정/제약: 충돌·단일 세션·정정 재계산의 복잡도.

## 대안과 금지 사항
- 브라우저 저장소의 토큰 저장, 서버 성공 전 저장 완료 표시, 채점 결과 덮어쓰기 — 금지.
- 신고 임계치만으로 오류 확정, 확인된 오류의 미적용 — 금지.
