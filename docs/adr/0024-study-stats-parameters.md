# ADR-0024: 학습 통계·취약 영역 파라미터

## 배경
- ADR-0021은 학습 현황(최초 풀이 고유/500·누적/영역 정답률·취약 영역 추천)을 규정하되, 정확한 계산 파라미터는 하위 BDD/ADR에서 근거와 함께 고정하도록 위임했다.
- 파라미터가 코드에만 있으면 통계 결과의 재현·리뷰·변경 통제가 어렵다.

## 결정
- **분모**: 시험별 500문제(주입 가능). `coverage = uniqueFirstSolved / totalQuestions`.
- **최소 표본**: 영역별 최초 풀이 고유 문제 5개 미만이면 `insufficient-data`로 표시하고 취약/양호를 단정하지 않는다. n=5에서 3/5=0.6과 2/5=0.4가 임계치 양쪽을 가른다.
- **반복 영향 제한**: 동일 attemptId 중복 제거 + 문제당 최근 채점 3회만 반영 + **문제당 동일 가중 평균**으로 한 문제의 장기 반복이 영역 정답률을 지배하지 않게 한다.
- **최근 창**: 14일. 최근 표본이 없으면 누적 정답률로 대체하고 `effectiveRecentAccuracy`로 노출한다.
- **취약 판정**: 결합 점수 = 누적×0.5 + 유효 최근×0.5. 점수 < 0.6인 영역만 오름차순으로 최대 3개 추천한다(4개 영역을 모두 취약으로 띄우지 않음).
- **첫 풀이**: 채점 가능한(correct/wrong) 최초 시도만 고유 풀이로 센다. Pass/미응답은 정답률 분모·고유 풀이에서 제외한다.
- **시험 분리**: `examId`가 다른 이력은 집계 전에 제외한다. 계산은 순수·결정적이며 외부 패키지/DB/네트워크에 의존하지 않는다.

## 결과
- 긍정: 통계 결과 재현·리뷰 가능, 반복·표본 부족 왜곡 제한, 시험별 확장.
- 부정/제약: 최소 표본 미달 영역은 초기에 추천되지 않음, 첫 Pass 이후 정답은 고유 풀이로 집계되지 않음.

## 대안과 금지 사항
- 단순 전체 시도 평균(반복 문제 지배) — 채택하지 않음.
- 표본 부족 영역을 취약으로 단정, 합격 가능성 예측·기간별 고급 그래프 — 범위 밖/금지.
- 파라미터 무단 변경 — 새 ADR 필요.
