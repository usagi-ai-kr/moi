# ADR-0051: 저장소 tmp/ 작업 디렉터리와 이슈 기반 인수인계

## 배경
- ADR-0048은 브리프·보고서를 `$TMPDIR/opencode/moi-work/`에, 인계 문서를 `docs/handover/`에 두었다. `$TMPDIR`는 `/var/...`와 `/private/var/...`로 표기가 섞이고 재부팅 시 사라질 수 있으며, `docs/handover/`에는 시점 스냅샷이 쌓인다.
- 사용자 결정(2026-10-20): 저장소 루트 `tmp/`를 gitignore하되 `.gitkeep`으로 디렉터리를 유지하고, 임시 문서·인수인계에 쓴다. 인계의 추적·공유는 이슈로 한다.

## 결정
- ADR-0048을 대체한다. 정지 절차·WIP 보존·절대 경로 원칙은 유지하고 위치만 바꾼다.
- 작업 디렉터리: `<repo root>/tmp/`(커밋 대상은 `tmp/.gitkeep`뿐). 브리프·보고서·콜백 로그·인계 초안은 **메인 저장소 `tmp/`의 절대 경로**로 전달한다. worktree의 `tmp/`는 쓰지 않는다.
- 정지 지시를 받으면 o는 새 외부 쓰기(PR·이슈 생성·병합·배포·push·새 단위 디스패치)를 멈춘다. 허용 범위는 지시가 명시한 인계 산출물뿐이다.
- 정지 순서: ① 패널별 중지 프롬프트(테스트·서버 종료, 미커밋 보존, 3줄 상태 응답 후 대기, 콜백 불필요) ② 폴백 타이머 해제 ③ 브랜치·SHA·미커밋·잔여 프로세스 확인 ④ `tmp/handover-<날짜>.md` 작성 → 인계 이슈(라벨 `tuck`, 현재 Milestone)에 본문으로 게시. 다음 o용 재개 프롬프트를 포함한다.
- 미커밋 워커 변경은 버리지 않고 `wip:` 커밋으로 보존하며 게이트 미검증을 표시한다.
- 인계는 `docs/`에 두지 않는다. 기존 `docs/handover/`는 제거하며(내용은 git 이력과 인계 이슈 #82·#176), 남겨야 할 결정·합의는 이슈로 처리하고 영속 규칙은 ADR·스킬로 승격한다.

## 결과
- 긍정: 경로 혼동 제거, 저장소에 시점 스냅샷 누적 방지(`docs/handover/` 제거), 인계가 이슈로 추적·공유된다.
- 부정/제약: `tmp/` 내용은 기기 로컬이라 공유되지 않는다. 남겨야 할 내용은 이슈·ADR·스킬로 승격해야 한다.

## 대안과 금지 사항
- `tmp/` 내용(브리프·보고서) 커밋 — 금지. 비밀값·토큰은 `tmp/`에도 남기지 않는다.
- 정지 지시 후 진행 중 단위의 PR·병합·배포를 "마무리"로 간주해 계속하는 것 — 금지.
