# ADR-0046: 학습 세트 10문제 조정

## 배경
- 새 학습 세트 20문제는 한 세션에 풀기 과다하다는 사용자 요청(#187). 한 번에 끝낼 수 있는 분량으로 줄인다.
- `STUDY_SET_SIZE = 20`(ADR-0020 결정 조항)은 생성·표시·테스트 전반에 박혀 있다.

## 결정
- 새 세트 크기를 10문항으로 조정한다: `STUDY_SET_SIZE = 10`.
- 기존 20문항 active 세트는 읽기 호환한다. `assertStudySetInvariants`는 세트 생성 시에만 호출되며(grep 확인), 읽기/풀이/제출 경로는 `items.length`를 강제하지 않으므로 기존 세트는 계속 풀고 제출할 수 있다.
- UI 문구는 상수 보간으로 일원화한다(`copy.ts`·`StartView`가 `STUDY_SET_SIZE` 참조). `HISTORY_PAGE_SIZE = 20`(이력 페이지네이션)은 건드리지 않는다.

## 결과
- 긍정: 한 세션 부담 절반, 문구·상수 단일 소스라 차후 조정 용이.
- 부정/제약: 기존 20문항 세트와 신규 10문항 세트가 통계·이력에 혼재한다(정답률은 세트 내 비율이라 비교 가능). 회귀 테스트(`use-cases.test.ts` LegacyCompat)가 20문항 세트의 풀이·제출 호환을 보증한다.

## 대안과 금지 사항
- 대안(기존 세트 강제 마이그레이션/무효화): 진행 중 학습을 깨뜨리므로 기각.
- 금지: 세트 크기를 하드코딩으로 분산(반드시 `STUDY_SET_SIZE` 참조), `HISTORY_PAGE_SIZE`를 세트 크기와 연동.
