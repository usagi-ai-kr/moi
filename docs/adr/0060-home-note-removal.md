# ADR-0060: 홈 안내 문구 삭제

## 배경
- ADR-0032가 홈 안내 문구(`copy.home.note`: 카카오 로그인 → 10문제 풀이 → 저장·결과 확인, 첫 범위는 AWS SAA)를 사실 문구로 명시했다.
- 사용자 명시 지시(사용 테스트 완료): 해당 문구를 삭제한다. 첫 화면은 브랜드·소개(lead)만으로 충분하다.
- 로그인 홈(`AuthenticatedApp` Home)은 해당 문구를 렌더하지 않아 변경 대상이 아니다.

## 결정
- ADR-0032의 브랜드·lead 계약(정적 h1/lead 즉시 렌더, CTA는 서버 상태에만 따름)은 그대로 승계한다.
- `copy.home.note` 키와 `LoggedOutView`의 해당 `<p className="moi-note">` 요소를 삭제한다(빈 문단을 남기지 않고 요소 자체 제거).
- `.moi-note` CSS는 다른 화면(통계·결과·문항 등)이 계속 사용하므로 유지한다.

## 결과
- 긍정: 사용자 확정 사항 반영, 홈 마크업 축소(초기 번들·LCP 계약 ADR-0018 유지).
- 부정/제약: 비로그인 홈에서 학습 흐름 안내 문구가 사라진다. 안내가 필요해지면 별도 이슈·문구로 다룬다.

## 대안과 금지 사항
- 문구 숨김(CSS `display:none`·빈 `<p>` 잔류) 금지 — 마크업에서 제거한다.
- 문구 삭제에 편승한 아키텍처·CSS·인증로직 변경 금지.
