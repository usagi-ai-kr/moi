# ADR-0076: 학습 범위 안내 정리·fieldset 위계와 문제 수 분리

## 배경
- 학습 시작 화면에 "현재 지원하는 시험은 1개입니다."와 옵션 나열 문구가 같은 위계로 중복 노출됐다 (#269).
- 설명·범위 라벨·선택 항목의 타이포·간격·선택 상태가 시각적으로 구분되지 않았다.

## 결정
- `copy.exam.note`를 삭제한다. 시험 선택의 단일 소스는 셸 상단 selector다 (#259, 최종 위치 #273).
- 홈의 시험 안내 섹션을 제거한다. 홈은 인사와 CTA만 둔다.
- `examContext`는 `한 회차에 10문제를 풉니다. 범위를 선택하세요.`로 줄인다. 옵션 나열 괄호만 제거한다.
- 범위는 네이티브 `fieldset`/`legend` 그룹으로 유지하고 설명은 `aria-describedby`로 연결한다.
- legend는 본문 크기·600·ink, 설명은 small·muted로 위계를 분리한다. 선택 상태는 색·도트에 더해 라벨 굵기로 구분한다.

## 결과
- 긍정: 시험→범위→문항 수→시작 순서가 명확해진다. 스크린리더는 group(범위)과 설명을 함께 읽는다.
- 부정/제약: 10문제 개수 표기는 #275 완료 전까지 유지한다. 카운트 문구 일괄 정리는 #275 몫이다.

## 대안과 금지 사항
- 4/8 선택기·10문제 계약 변경은 #275 소유 — 이 결정에서 금지한다.
- 별도 '문제 수' fieldset 분리는 #275에서 처리한다.
