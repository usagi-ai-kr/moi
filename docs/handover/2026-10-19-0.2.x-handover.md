## 3. 현재 계약

### 인증·세션
- Kakao OIDC Authorization Code + PKCE S256, state 일회성·브라우저 바인딩, ID token JWKS/iss/aud/exp/nonce 검증.
- PASETO v4.local 세션 24h, D1 jti 해시 폐기, `__Host-moi_session`(Secure/HttpOnly/SameSite=Lax/Path=/).
- `GET /api/me`, `POST /auth/logout` CSRF.

### 학습 API
- `POST /api/study/sets` — 세트 시작(동시 시작 409 가드)
- `GET /api/study/sets/:id` — active/submitted. 제출 전 정답·해설 미노출
- `PATCH /api/study/sets/:id/answers` — 답안 저장
- `POST /api/study/sets/:id/submit` — 조건부 제출 + `study_attempts` 원자 저장
- `POST /api/study/sets/:id/abandon`
- `GET /api/study/sets?page=&pageSize=` — 완료 이력
- `GET /api/study/sets/:id/corrections` — `{items, corrected}`
- `GET /api/study/stats?examId=` — 학습 현황
- `POST /api/study/reports` — 문제 신고
- `POST /api/admin/study-sets/:id/corrections` — admin Bearer write 정정 적용

### 데이터
- `study_sets`/`study_set_items`: 부분 UNIQUE로 계정·시험당 active 1개.
- `study_attempts`: attemptId PK, `(source,sourceId,questionId)` UNIQUE, `excluded_at`, `first_attempt`. 통계는 excluded 제외.
- `study_corrections`: `(set_id, question_version_id)` UNIQUE, actor 기본 system.
- migration `0000`~`0010` 로컬 존재. **원격 D1 적용·백업/복구 리허설은 미완료로 취급**.

- **ADR-0025가 `Proposed`로 남아 있다.** attempt 저장 계약은 #98~#123으로 구현·검증됐지만 ADR 상태 전환은 별도 판단이 필요하다. 완료로 간주하지 말고 `Accepted` 전환 여부를 검토한다.
